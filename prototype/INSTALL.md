# 安装与运行说明（给组员）

> COMP 3500SEF / 8500SEF 软件工程小组项目 —— 选举管理与投票系统
> 这份文件专门写给拿到压缩包的同学，**3 步就能跑起来**。

---

## 一、你需要什么

| 项目 | 要求 |
|---|---|
| Python | **3.10 或更高**（开发环境为 3.12）。在终端运行 `python3 --version` 确认 |
| 网络 | 首次打开页面需要联网加载图表库（jsdelivr CDN）。**没有网络也能投票**，只是统计图表不显示 |
| 其他 | **不需要**数据库服务器、不需要 Node.js、不需要 Docker |

> 没装 Python？macOS 用 `brew install python@3.12`；Windows 到 python.org 下载安装包，
> 安装时记得勾选 **Add Python to PATH**。

## 二、三步跑起来

```bash
# 第 1 步：解压后进入目录
cd election-system

# 第 2 步：安装唯一的依赖
pip3 install -r requirements.txt

# 第 3 步：启动
cd backend && python3 app.py
```

看到这样的输出就成功了：

```
================================================================
 选举管理与投票系统 — COMP 3500SEF / 8500SEF
================================================================
 ✔ 已生成演示数据集（4 场选举 / 190 名选民 / 预投选票）
```

浏览器打开 **http://localhost:8767**

> 如果 `pip3` 不存在，试 `python3 -m pip install -r requirements.txt`。
> Windows 上把 `python3` 换成 `python`。

## 三、怎么用（重点：投票是 4 步）

```
1 选民登录  →  2 选择要参与的选举  →  3 选择候选人  →  4 确认投票
```

**选民登录**
- 选民编号：例如 `HK100035`
- PIN：`1234`
- 不知道编号？点页面上的 **「填入第一个可用选民」** 按钮会自动填好。
  （若看不到这个面板，点右上角 **⚙️ 设置** → 勾选「显示演示辅助信息」）

**选择候选人**：投票页会列出本场选举的候选，**点击即可选中**。
- 单选制场次：点一个即可
- 排序复选制场次（IRV）：按偏好顺序依次点击，会显示 `1.` `2.` `3.`

**投完票**会拿到一个**凭证码**（形如 `5KWV-7N5F-V6SM`），
在「凭证核验」里输入它可以确认"我的票已计入且未被修改"。
注意：凭证**不会**显示你投给了谁 —— 这是有意设计，防止被胁迫或贿选。

**管理员**：右上角 **⚙️ 设置 → 🧑‍💼 管理员登录**，账号 `admin`，密码 `admin123`。

## 四、值得一看的四个功能

| 功能 | 位置 | 看点 |
|---|---|---|
| 防重复投票 | 投票页 | 投完再投会被拒；这是**数据库唯一约束**，不是前端限制，并发也拦得住 |
| 排序复选制计票 | 管理台 → 计票 | 同一批选票，单选制与排序复选制会选出**不同的人**，看逐轮淘汰记录 |
| 完整性校验 | 管理台 → 完整性校验 | 三项数据不变量一键体检 |
| **篡改演练** | 管理台 → 审计链与篡改演练 | 点「模拟篡改」→ 审计链立刻断裂并定位到具体记录 → 点「还原」恢复 |

## 六、常见问题

**Q: 端口 8767 被占用？**
```bash
PORT=9000 python3 app.py          # macOS / Linux
set PORT=9000 && python app.py    # Windows
```

**Q: 想重新生成演示数据？**
删掉 `data/` 目录再启动即可：
```bash
rm -rf data && cd backend && python3 app.py
```
（Windows 用 `rmdir /s /q data`）

**Q: 页面图表空白？**
图表库走 CDN，需要联网。**不影响投票、计票、审计等核心功能**。

**Q: 提示 `ModuleNotFoundError: No module named 'flask'`？**
依赖没装成功，回到第 2 步。若系统禁止写全局环境，用虚拟环境：
```bash
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

**Q: 数据会丢吗？**
不会。数据存在 `data/election.db`（SQLite 文件），重启后仍在。
这也正是它和"内存假数据原型"的关键区别。

**Q: 为什么每人只看到一场选举？**
每个人名册不同。点「填入第一个可用选民」拿到的是当前可投票的人；
不同编号可能看到不同的选举列表 —— 这本身就是需求"只有名册内选民能投票"的体现。
